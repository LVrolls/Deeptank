# DEEP TANK · 深海水槽

> 一个可以放在屏幕角落慢慢养的深海水族箱经营游戏。单个 HTML 文件，双击即玩，无需安装、无需联网、无广告、无追踪。

**[▶ 在线试玩](https://lvrolls.github.io/Deeptank/index.html)**

---

## 这是什么

你经营一座深海水族馆。养鱼、调水质、选育基因、派队下潜、收集标本。

它被设计成**决策多但点击少**——不需要连点，不需要盯着屏幕。每次回来花半分钟做几个判断，然后就可以放着不管。窗口能缩到很小，挂在屏幕角落也不吵。

同时它又不只是个挂机游戏：真正的进度来自主动玩法，挂机只能维持基础运转。

---

## 核心玩法

### 养活它

温度和水质两条滑杆，每个鱼种有各自的舒适区间。混养就得找折中点——色带会画出每种鱼的适应范围，青色框是共同区间。

污染会压低有效水质，把色带整体右推；密度太高也一样。研究出生态过滤后可以自动清理。

### 选育

每条鱼有三项独立基因：

| 基因 | 作用 | 方向 |
|---|---|---|
| **产出** | 气泡产量，同时决定远征采集效率 | 越高越好（0.50–2.00）|
| **耐受** | 水质舒适区加宽，降低远征失踪率与氧气消耗 | 越高越好 |
| **繁育** | 配对后的冷却秒数 | **越短越好**（34–128 秒）|

后代取双亲平均值加随机偏移。连续挑最好的配对是真能推上去的——但三项没法同时拉满，得决定要什么。

还有形态变异：原色 / 虹彩 / 极光。极光只能靠繁殖变异、深度 6 以上的远征卵，或苗场传承卵获得。

### 远征

**这是游戏的核心循环**，也是「结晶」这种硬通货的主要来源。

派 1–4 条成鱼组队下潜。每推进一段会遇到一次事件，然后**停下来等你决定：继续深入，还是带着战利品返航**。

- 队伍共享**氧气条**，越深消耗越快
- 货舱里的东西**只有返航才入账**；氧气耗尽会强制上浮并损失 35%
- 深度决定收获质量：卵的鱼种上限约为 `1 + 深度/2`，极光需要深度 6 以上
- 队员会积累勘探经验（新手→熟手→老手→传奇），老兵明显更安全
- 掠食者只会盯上一条队员，逃脱率由耐受基因和经验决定

6 个海域，最深 16 层。10 种遭遇：矿脉、结晶簇、异常读数、卵鞘、古代残骸、未知生物、逆流、掠食者、静水区、补给残骸。

### 展馆

一座类似博物馆的收藏系统。**每个鱼种的每种颜色只能收录一次，捐进去就拿不回来。**

45 个展位排成表格，每行一个鱼种、横向三格对应三种形态。格子有三种状态：亮色鱼形＝已入藏，暗色＝图鉴见过但没捐，空白＝还没见过。

展品会记录捐赠时的基因品质，**5 星个体的展品价值是 1 星的 2.35 倍**，而门票收入是永久的。后来配出更好的个体还能**替换升级**旧展品。

这里也是「配出好鱼有什么用」的主要答案。

### 双货币

- **气泡** — 日常运转：投饵、买鱼、布景、展馆升级。挂机也能攒
- **结晶** — 关键解锁：新水槽、声呐、深渊名录、苗场、高级鱼种。**只能从主动玩法获得**，挂再久也拿不到一颗
- **数据** — 研究树 + 可无限升级的「深渊理论」

## 上手三步

1. 到「鱼群」页买一条**玻璃小鱲**（对水质要求最宽松）
2. 回顶部把温度滑进它的色带里
3. 到「水槽」页投一次饵

之后就可以放着。等它长成成鱼，再去「远征」页派它下潜看看。

## 特性

- **单文件**，零外部依赖，不联网，不加载任何 CDN
- **离线结算**：关掉页面照样在跑，回来自动补算（前 2 小时全额，之后 35% 折算，上限 8 小时）
- **自适应布局**：手机单栏；桌面 ≥880px 自动切双栏，鱼缸常驻左侧不会被滚动挤走
- **存档安全**：双后端写入 + 滚动备份 + 旧版本自动迁移；支持导出/导入存档码跨设备搬家
- **无音效**，不打扰

## 存档说明

进度保存在**你自己浏览器的 localStorage** 里（键名 `deeptank.v3`），不上传任何服务器。

因此：换浏览器、换设备、清理浏览数据、无痕窗口都会读不到。「研究」页底部的**存档面板**会显示当前存储状态；如果环境不允许保存（例如 Safari 直接打开本地文件），会明确警告而不是让你白玩几小时。

要跨设备搬进度，用存档面板的**导出/导入存档码**。

> ⚠️ iOS Safari 直接打开本地 HTML 文件（`file://`）会禁用 localStorage，进度存不住。请通过 GitHub Pages 之类的网址访问。

## 部署

任何静态托管都行，上传这一个文件即可。

**GitHub Pages**：把文件命名为 `index.html` → 仓库 `Settings` → `Pages` → Source 选 `Deploy from a branch` → Branch 选 `main` + `/ (root)` → Save。等 1–10 分钟即可访问。

在手机 Safari 里打开后可以「**添加到主屏幕**」，会变成全屏图标，跟原生 App 差不多。

## 开发

没有构建步骤，没有依赖。直接编辑 `index.html` 即可——所有 CSS 和 JS 都内联在里面。

大致结构：

```
<style>        样式与响应式断点
SPECIES/MORPH  鱼种与形态数据表
ZONES/ENC      海域与远征遭遇表
RESEARCH       研究树、遗物、科研项目、传承特性
step()         主模拟循环（水质、成长、繁殖、事件）
diveTick()     远征推进与结算
hallScore()    展馆评分
tabXxx()       六个标签页的界面渲染
render()       Canvas 绘制（鱼、布景、气泡）
save/load      存档、迁移、导出导入
```

调平衡最常动的几个常量：`FISHK`（鱼的基础产出系数）、`THEORY`（无限研究成本曲线）、`ZONES[*].pay`（各海域回报）、`hallStars` 的星级阈值。

## 已知取舍

- 后期收入的绝大部分来自**展馆门票**，鱼自身的产出占比较小。这是有意的——收入基于收藏评分（加权和）而非每条鱼的乘法叠加，这样不会指数爆炸。如果想让养鱼本身更有存在感，调高 `FISHK` 即可。
- 深渊平原标称 12 层，但实际很难潜到底——需要高耐受基因的老手队员或传承特性「高压气瓶」。这是刻意的门槛。
